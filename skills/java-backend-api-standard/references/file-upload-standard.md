# 文件上传生产标准

## 1. 目标

文件上传不能按普通 JSON API 简单处理。公司级标准必须明确上传大小、类型、存储、扫描、访问权限和审计边界。

## 2. 推荐模式

小文件：

```text
client -> API -> FileUploadSecurityPolicy -> object storage
```

大文件：

```text
client -> API 获取预签名 URL -> object storage 分片/直传 -> API 提交文件引用
```

规则：

- 大文件优先对象存储预签名上传，不把完整文件字节放入普通 API 签名。
- API 只信任服务端生成的对象 key 和文件引用。
- 文件名不得直接作为服务端路径。

## 3. 校验要求

最低要求：

- 限制大小。
- 限制扩展名。
- 限制 content type。
- 生产增加魔数校验。
- 生产接入杀毒、内容扫描或公司批准的对象存储安全策略。

禁止：

- 信任客户端原始文件名。
- 返回永久公开 URL。
- 让前端传入任意存储路径。
- 在日志中记录包含敏感信息的完整文件内容。

## 4. 审计与权限

必须审计：

- 上传。
- 删除。
- 下载授权。
- 权限变更。

访问 URL 必须有权限控制、有效期或签名策略。导出文件同样适用本标准。
