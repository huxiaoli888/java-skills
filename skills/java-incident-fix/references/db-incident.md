# 数据库事故参考

用于慢 SQL、连接池耗尽、锁等待、死锁、数据损坏、局部写入和数据修复。

## 需要采集的证据

- 慢 SQL 样例。
- 连接池活跃、空闲和等待指标。
- 锁等待或死锁日志。
- 近期表结构、索引、SQL 或流量变化。
- 受影响表和行数。
- 代码中的事务边界。
- Mapper XML 或 repository 方法。

## 常见原因

| 现象 | 可能原因 |
| --- | --- |
| 连接池耗尽 | 慢 SQL、连接泄漏、事务过大、事务中调用下游 |
| 慢查询 | 缺少索引、全表扫描、动态 SQL 错误、无界分页 |
| 死锁 | 更新顺序不一致、长事务、批量更新冲突 |
| 数据不一致 | 局部提交、缺少事务、重复请求、MQ 重试缺少幂等 |

## 止血

- 限流或关闭受影响链路。
- 如果数据正在被错误写入，停止写入。
- 回滚触发问题的 SQL、代码或配置。
- 只有经 DBA 批准后，才能终止危险长查询。
- 只有经 DBA 评审后，才能增加临时索引。

## 数据修复保护

1. 查询影响范围。
2. 导出受影响行。
3. 准备幂等修复 SQL。
4. 准备回滚 SQL。
5. 小批量执行。
6. 校验数量和业务不变量。

## 代码复核点

- `@Transactional` location and rollback rules.
- 事务内是否存在远程调用。
- 幂等唯一约束。
- 动态 SQL 分支。
- 分页和排序。
- 表的读写归属。
