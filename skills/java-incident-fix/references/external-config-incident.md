# 外部调用与配置事故参考

用于 Feign/RPC 超时、下游故障、重试风暴、配置漂移、Nacos/Apollo 问题、调度任务配置错误和发布 profile 不匹配。

## 外部调用证据

- 目标系统和操作。
- 超时配置。
- 错误率和延迟分布。
- 重试次数和重试间隔。
- 熔断器或 fallback 状态。
- 跨上下游的 trace id。
- 提供方事故状态。

## 外部调用止血

- 降级可选依赖。
- 隔离故障下游。
- 线程池耗尽时缩短超时。
- 停止不安全重试。
- 对受影响链路限流。
- 与下游负责人协同。

## 配置证据

- 当前运行时配置。
- 最近稳定配置。
- 近期配置发布历史。
- 当前 profile 和环境。
- 功能开关。
- Nacos/Apollo namespace/group/dataId。

## 配置止血

- 明确由配置触发时，优先回滚配置。
- 事故期间冻结进一步配置变更。
- 验证所有实例已收到相同配置。
- 只有动态刷新未生效且重启安全时才重启。

## 调度任务检查

- 多实例重复执行。
- Cron 表达式变化。
- 锁/分片行为。
- 最近一次成功运行。
- 批大小和分页。
- 追赶执行导致的下游压力。
