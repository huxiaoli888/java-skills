## 备选方案

| 方案 | 优点 | 缺点 | 是否采用 |
| --- | --- | --- | --- |
| Netty WebSocket | 高并发长连接、控制力强 | 实现复杂度较高 | 是 |
| Netty TCP | 私有长连接、二进制协议、设备连接 | 需要自定义拆包/粘包和认证 | 视场景 |
| Netty UDP | 低延迟短报文、弱可靠探测 | 丢包、乱序、重复处理复杂 | 视场景 |
| Spring WebSocket | 集成简单 | 高并发和协议控制较弱 | 否 |
| 每个动作一个连接 | 入口直观 | 连接管理复杂、复用差 | 否 |
| 单连接按 func 分发 | 连接复用、扩展清晰 | 需要协议 envelope | 是 |
